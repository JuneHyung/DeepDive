# 가족 여행 준비 하네스

이 프로젝트는 부모님과 함께하는 여행 준비를 Agent/Skill/Orchestrator 구조로 다룹니다.

## 자연어 라우팅 규칙

사용자가 아래와 비슷한 요청을 하면 **반드시 `family-trip-orchestrator` Skill을 먼저 사용**합니다. 사용자가 스킬명이나 에이전트명을 직접 말하지 않아도 의도를 보고 판단합니다.

### 트리거 예시
- "부모님 모시고 여행 가고 싶어"
- "엄마 아빠랑 2박 3일 어디 갈까?"
- "가족 여행 준비해줘"
- "70대 부모님이랑 강릉 여행 계획 짜줘"
- "어버이날 여행 어디로 갈지 추천해줘"

### 단일 Agent 직접 호출이 적절한 경우
사용자가 명확하게 특정 단계만 요청할 때는 해당 subagent를 직접 사용해도 됩니다.

- "여행지 후보만 추천해줘" → `destination-scout`
- "이 일정으로 짐만 정리해줘" → `packing-curator`
- "출발 전 점검만 해줘" → `pre-trip-reviewer`

## 팀 구성

| Agent | 역할 |
|---|---|
| `destination-scout` | 부모님 취향·체력 고려한 후보지 정찰 |
| `itinerary-planner` | 2박 3일 시간표 설계 |
| `booking-coordinator` | 숙소·교통 예약 체크리스트 |
| `packing-curator` | 짐과 약품 목록 |
| `pre-trip-reviewer` | 출발 전 최종 점검 |

## 산출물 4종
1. 여행 계획서 (3일 일정표)
2. 예약 체크리스트
3. 짐 목록
4. 최종 점검 리포트

## 안전 원칙
- 부모님 건강 정보(복용 약, 관절 상태, 알레르기)는 명시적으로 묻고 모든 산출물에 반영합니다.
- 실제 예약·결제는 사용자가 직접 합니다. Agent는 "무엇을 예약해야 하는지" 정리만 합니다.
- 위급 시 연락처와 가까운 병원 정보를 최종 점검에 포함합니다.
