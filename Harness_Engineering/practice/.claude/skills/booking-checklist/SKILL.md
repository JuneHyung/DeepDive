# Skill: 예약 체크리스트 작업법

## 언제 트리거되는가
- 사용자가 "예약 뭐 해야 해?", "숙소 정리해줘", "예약 체크리스트"를 요청할 때
- itinerary-planner가 일정을 완성한 후
- booking-coordinator 에이전트가 호출되었을 때

## 절차

### 1. 일정에서 예약 항목 추출
일정 안의 `[예약필요]` 태그 + 일반적으로 예약이 필요한 항목을 모은다.
- 숙소 (모든 박)
- 교통 (KTX, 항공, 렌터카)
- 인기 식당 (특히 주말)
- 시간 지정 입장권 (전시, 박물관, 케이블카 등)

### 2. 각 항목에 부모님 친화 옵션 메모
- 숙소: 1층 객실 / 엘리베이터 / 침대형 / 욕실 손잡이
- 교통: 통로석 / 노약자석 가능 여부 / 짐 부피
- 식당: 좌식 vs 입식, 부드러운 음식 메뉴 유무

### 3. 예약 시점 권장
- 숙소: 출발 2~3주 전
- 인기 식당: 1~2주 전
- 시간 지정 입장권: 1주 전
- 교통: 시기에 따라 다름 (성수기는 1개월 전)

### 4. 예상 비용 범위
가격을 단정하지 말고 범위로 표기 (예: "1박 12~18만원").

## 산출물 형식

```
## 예약 체크리스트

### 숙소
| □ | 항목 | 예약 시점 | 예상 비용 | 부모님용 옵션 |
|---|---|---|---|---|
| □ | (숙소명/지역) Day1 | 2~3주 전 | 12~18만원 | 1층 or 엘리베이터 |
| □ | (숙소명/지역) Day2 | 2~3주 전 | ... | ... |

### 교통
| □ | 항목 | 예약 시점 | 예상 비용 | 메모 |
|---|---|---|---|---|
| □ | (출발지→여행지) | 1주 전 | ... | 통로석 |

### 식당 (선택)
...

### 입장권 (선택)
...

## 총 예상 비용
약 (X만원 ~ Y만원)

## 안내
실제 예약은 사용자가 직접 진행해야 합니다. 결제 정보는 제가 입력하지 않습니다.
```

## 품질 체크
- [ ] 일정의 모든 숙박이 포함되었는가
- [ ] 모든 비용이 범위 형식으로 표기되었는가
- [ ] 부모님 친화 옵션이 각 항목에 명시되었는가
- [ ] 총 예상 비용 합계가 있는가
- [ ] 사용자가 직접 예약한다는 안내가 있는가
