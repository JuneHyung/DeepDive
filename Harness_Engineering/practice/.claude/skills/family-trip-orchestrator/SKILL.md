# Skill: 가족 여행 준비 오케스트레이터

## 언제 트리거되는가
- "부모님 모시고 여행 가고 싶어"
- "엄마 아빠랑 2박 3일 어디 갈까?"
- "가족 여행 준비해줘"
- "어버이날 여행 계획 짜줘"
- "70대 부모님 여행 어디로?"

사용자가 스킬명을 직접 부르지 않아도, 가족 여행 준비 의도가 보이면 이 매뉴얼을 따른다.

## 사전 점검 — 입력 확인

진행하기 전에 다음 정보를 확인한다. 빠진 게 있으면 **모든 단계를 시작하기 전에** 한 번에 묻는다.

```
부모님 여행 준비를 도와드리기 위해 몇 가지 알려주세요:
1. 부모님 연령대와 건강 상태 (관절, 지병, 알레르기, 복용 약)
2. 출발지
3. 여행 시기 (출발일/복귀일)
4. 이동 수단 (자차 / 대중교통)
5. 선호하는 분위기 (자연·휴양 / 도시·문화 / 음식 위주)
6. 대략의 예산 범위 (선택)
```

## 진행 순서 (5단계)

### 1단계 — 후보지 정찰
- 호출: `destination-scout` 에이전트
- 산출: 후보 3~5곳 비교표
- 사용자 확인 필요: 1곳 선택 받기
- **중단 조건**: 사용자가 선택할 때까지 다음 단계로 가지 않는다.

### 2단계 — 일정 설계
- 호출: `itinerary-planner` 에이전트
- 입력: 선택된 여행지 + 사전 점검 정보
- 산출: Day1/2/3 시간표 (`[예약필요]` 태그 포함)

### 3단계 — 예약 체크리스트
- 호출: `booking-coordinator` 에이전트
- 입력: 2단계 일정
- 산출: 카테고리별 예약 체크리스트 + 총 예상 비용

### 4단계 — 짐 목록
- 호출: `packing-curator` 에이전트
- 입력: 일정 + 부모님 건강 정보 + 계절
- 산출: 카테고리별 짐 목록 + TOP 5
- **필수**: 복용 약 정보가 없으면 사용자에게 추가 질문 후 진행

### 5단계 — 최종 점검
- 호출: `pre-trip-reviewer` 에이전트
- 입력: 2·3·4단계 산출물 모두
- 산출: ✅/⚠️/🚨 리포트 + 비상 정보 박스 + D-1 액션

## 실패 시 대응

| 상황 | 처리 |
|---|---|
| 사전 점검에서 정보가 너무 부족 | 추측하지 않고 사용자에게 묻는다 |
| 후보지에 사용자가 만족하지 않음 | 조건을 받아 destination-scout 재호출 |
| 일정이 너무 빡빡하다고 사용자가 말함 | itinerary-planner 재호출 (체력 "하" 가정) |
| 최종 점검에서 ⚠️/🚨 발견 | 해당 단계 에이전트로 되돌려 보완 |
| 약 정보 없음 | 짐 목록 완성 거부, 사용자에게 질문 |

## 최종 응답 형식

5단계가 모두 끝나면 다음 4개 산출물을 묶어 한 번에 전달한다.

```
# 가족 여행 준비 완료 — (장소명) 2박 3일

## 📄 1. 여행 계획서
(itinerary-planner 결과)

## 📄 2. 예약 체크리스트
(booking-coordinator 결과)

## 📄 3. 짐 목록
(packing-curator 결과)

## 📄 4. 최종 점검 리포트
(pre-trip-reviewer 결과)

## 다음 행동
1. 예약 체크리스트의 ☐을 사용자가 직접 예약하며 채우기
2. 출발 D-1에 최종 점검 리포트의 액션 항목 실행
3. 다녀온 후 Evolution 메모 남기기 (무엇이 어긋났는지, 다음에 어떻게 고칠지)
```

## 품질 체크
- [ ] 5단계를 모두 거쳤는가
- [ ] 사용자에게 후보지 선택을 받았는가
- [ ] 복용 약 정보를 확인했는가
- [ ] 최종 점검 리포트에 ⚠️/🚨가 있는가 (없으면 검토 부실)
- [ ] 마지막에 "다음 행동" 3가지를 제시했는가
