# Skill: 최종 점검 작업법

## 언제 트리거되는가
- 사용자가 "출발 전 점검", "다 빠진 거 없어?", "최종 확인"을 요청할 때
- 다른 에이전트들이 일정·예약·짐 산출물을 완료한 후
- pre-trip-reviewer 에이전트가 호출되었을 때

## 절차

### 1. 산출물 3종 모으기
- 일정 (itinerary-planner 결과)
- 예약 체크리스트 (booking-coordinator 결과)
- 짐 목록 (packing-curator 결과)

### 2. 교차 검토 (가장 중요)
- 일정에 있는 모든 숙박이 예약 체크리스트에 있는가
- 예약 체크리스트의 항목 중 일정에 없는 게 있는가
- 짐 목록의 약이 일정 일수보다 충분한가 (3박 = 4일분 이상 권장)
- 짐 목록에 예약 확인서가 들어있는가
- 일정의 활동에 필요한 짐이 빠지지 않았는가 (예: 등산 → 등산화)

### 3. 안전·건강 점검
- 부모님 복용 약 ✓
- 신분증/건강보험증 ✓
- 여행지 가까운 응급실 확인 ✓
- 비상 연락처 (보호자, 가족, 보험사) ✓
- 식이 제한 시 안전한 식당 옵션 확인 ✓

### 4. 위험 등급 분류
- ✅ 잘 준비된 항목
- ⚠️ 보완 필요 (어느 Agent로 되돌릴지 명시)
- 🚨 위험·누락 (출발 전 반드시 해결)

## 산출물 형식

```
## 최종 점검 리포트

### ✅ 잘 준비된 항목
- (구체 항목 3개 이상)

### ⚠️ 보완 필요
| 항목 | 문제 | 해결 방향 | 담당 |
|---|---|---|---|
| (예) Day2 점심 식당 | 좌식이라 부모님 무릎 부담 | 입식 식당으로 변경 | itinerary-planner |
...

### 🚨 위험·누락
| 항목 | 영향 | 즉시 조치 |
|---|---|---|
| (예) 어머니 혈압약 명시 없음 | 건강 직접 위험 | 약 이름과 4일분 확인 |
...

### 비상 정보 박스
- **여행지 응급실**: (병원명/위치 — 정보 부족 시 사용자에게 확인 요청)
- **보호자 연락처**: (사용자에게 입력 요청)
- **복용 약 비상 메모**: (약 이름·복용 시점·담당 의사 연락처)
- **보험사 긴급 연락**: (해당 시)

### 출발 D-1 액션
오늘 안에 해야 할 일:
1. ...
2. ...
3. ...
```

## 품질 체크
- [ ] ✅/⚠️/🚨 세 영역이 모두 채워졌는가 (⚠️ 또는 🚨가 0이면 검토 부실 의심)
- [ ] 보완 필요 항목마다 어느 Agent로 되돌릴지 명시되었는가
- [ ] 비상 정보 박스가 비어있지 않은가
- [ ] "괜찮아 보입니다"로 끝나지 않았는가
- [ ] D-1 액션이 3개 이상 있는가
