# Skill: 짐 목록 작업법

## 언제 트리거되는가
- 사용자가 "짐 뭐 챙겨야 해?", "준비물 정리해줘", "짐 목록"을 요청할 때
- 일정·예약이 어느 정도 확정된 후
- packing-curator 에이전트가 호출되었을 때

## 절차

### 1. 필수 질문 (정보가 없으면 반드시 묻기)
- [ ] 부모님이 복용 중인 약이 있나요? (이름과 복용 빈도)
- [ ] 보조 기구를 사용하시나요? (돋보기, 지팡이, 보청기 등)
- [ ] 알레르기·식이 제한이 있나요?
- [ ] 여행 시기의 날씨 예보를 확인하셨나요?

복용 약 정보 없이 짐 목록을 완성하지 않는다.

### 2. 카테고리별 작성
1. **의류** — 날씨와 활동 강도 기준
2. **약·의료** — 복용 약 + 상비약 (해열, 소화, 상처, 멀미)
3. **세면·위생** — 부모님 평소 사용 제품 우선
4. **전자기기** — 충전기, 보조배터리, 멀티탭
5. **서류** — 신분증, 건강보험증, 예약 확인서
6. **부모님 전용** — 보조 기구, 평소 즐기시는 간식

### 3. 소유자 표시
각 품목에 (본인 / 부모님 / 공용) 태그를 단다.

### 4. TOP 5 강조
절대 빠뜨리면 안 되는 5개를 따로 박스로 강조한다.

## 산출물 형식

```
## 짐 목록

### 🚨 절대 빠뜨리면 안 되는 TOP 5
1. 부모님 복용 약 (3일치 + 예비 1일치)
2. 신분증 / 건강보험증
3. 예약 확인서 (인쇄 또는 캡처)
4. 휴대폰 충전기
5. (계절 필수품 - 예: 여름 모자 / 겨울 핫팩)

### 의류
| □ | 품목 | 수량 | 소유자 | 비고 |
|---|---|---|---|---|
| □ | 상의 | 3 | 본인 | |
| □ | 상의 | 3 | 부모님 | 어머니/아버지 각각 |
...

### 약·의료
| □ | 품목 | 수량 | 소유자 | 비고 |
|---|---|---|---|---|
| □ | (어머니 복용 약 A) | 4일분 | 부모님 | 아침/저녁 |
| □ | 해열제 | 1 | 공용 | |
...

### 세면·위생
...

### 전자기기
...

### 서류
...

### 부모님 전용
...
```

## 품질 체크
- [ ] 복용 약 항목이 구체적인가 (이름·복용 시점)
- [ ] 본인/부모님/공용 구분이 명확한가
- [ ] TOP 5에 약과 신분증이 포함되었는가
- [ ] 계절·일정에 맞춰 조정되었는가 (일반 템플릿이 아닌가)
- [ ] 예약 확인서가 포함되었는가
