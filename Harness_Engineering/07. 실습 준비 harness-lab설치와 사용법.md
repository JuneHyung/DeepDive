#  ★ 07. 실습 준비: harness-lab설치와 사용법

**🔖각 실습에서 사용하는 harness-lab 세팅**

**🔖처음에는 청사진만 만들고, 필요할 때만 실행 가능한 하네스 구성을 승인한다.**

## 🎯 이 장을 읽고 나면 알게되는 3가지

* `harness-lab`이 무엇인지 이해한다.
* Claude Code에서 `/harness-lab`을 사용할 수 있도록 설치한다.
* 각 장의 실습을 `청사진`과 `실행 하네스` 2단계로 나누어 진행하는 법을 익힌다.

> 출처
>
> [Github - harness-lab](https://github.com/jikime/harness-lab)
>
> `revfactory/harness`를 만드신 카카오의 황민호님의 스킬을 기반으로, 이 책의 실습 흐름에 맞게 재구성한 것.

<br/><br/>

**harness-lab**은 일을 대신 끝내주는 자동화 도구라기보다, 사용자의 일을 Agent, Skill, Orchestrator, Test, Evolution 구조로 바꾸어 보게 돕는 연습용 스킬이다. (실습 조교 느낌)



**harness-lab클론 후**

* 개인용 스킬로 설치하면 모든 Claude Code 프로젝트에서 harness-lab사용 가능
* 특정 프로젝트에서만 사용하고싶다면, 해당 프로젝트 루트에 프로젝트용 스킬로 복사해도 된다.

<br/>

**진행 순서**

1. 해당 장을 읽고 핵심 비유와 표를 확인한다.
2. 실습 프롬프트를 Claude Code에 입력한다.
3. harness-lab이 만든 청사진을 읽는다.
4. 책에서 배운 개념과 청사진 역할, 절차, 검증방법을 비교
5. 청사진만으로 충분하면 멈춤.
6. 계속쓸 하네스가 필요하면 실행 하네스 생성을 승인
7. 결과가 마음에 들지 않으면 어떤 역할, 절차, 검증이 부족헀는지 말하고 다시개선.

<br/><br/>

## 청사진과 실행 하네스 차이

| 단계        |                                                              |                                           |
| ----------- | ------------------------------------------------------------ | ----------------------------------------- |
| 청사진      | Agent, Skill, Orchestrator, Test, Evolution의 설계안 보여줌  | 개념을 이해하고 실습 결과를 검토할 때     |
| 실행 하네스 | 승인 후 Claude Code 프로젝트 안에 실제 Agent와 Skill 구성 만듬 | 같은 일을 반복해서 실제로 수행하고 싶을때 |

`harness-lab`은 기존 Claude Code 설정을 먼저 확인한 뒤, 필요한 Agent와 Skill을 구성하는 흐름으로 진행된다.

<br/><br/>

## 문제가 생겼을 때

`harness-lab`이 동작하지 않으면 아래를 먼저 확인

1. `./claude/skills/harness-lab/SKILL.md`파일이 있는가?
2. Claude Code를 새로 열었는가?
3. Cluade Code안에 사용가능한 스킬 목록을 확인했는가?

```
사용 가능한 스킬 목록을 보여줘.
```

```
먼저 청사진만 보여줘.
내가 승인하기 전에는 실제 파일을 만들지마.
```
