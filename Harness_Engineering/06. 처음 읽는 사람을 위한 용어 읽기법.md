#  ★ 06. 처음 읽는 사람을 위한 용어 읽기법

**🔖AI 에이전트, 하네스, 컨텍스트 MCP등 낯선 용어들을 일상 장면으로 바꿔 머릿속에 그릴 수 있도록한다.**

좀더 자세히 확인하고 싶다면, `부록A` 참고

| 어려운 용어 | 일상생활 비유                         | 한 문장 의미                                         |
| ----------- | ------------------------------------- | ---------------------------------------------------- |
| LLM         | 똑똑하지만 기억이 제한된 신입 사원    | 말을 이해하고 생성하는 모델                          |
| 모델 가중치 | 신입사원의 두뇌와 훈련된 습관         | 모델이 배운 지식과 패턴                              |
| 프롬프트    | 업무 지시서                           | 모델에게 지금 무엇을 하라고 말하는 문장              |
| 컨텍스트 창 | 지금 책상위에 펼쳐진 자료             | 모델이 한 번에 볼 수 있는 정보 공간                  |
| 토큰        | 문장을 잘게 자른 조각                 | 모델이 읽고 쓰는 최소 단위에 가까운 조각             |
| 도구 호출   | 직원이 회사 시스템 버튼을 누르는 일   | 답변 전 관련 문서를 검색해 컨텍스트에 넣는 방식      |
| RAG         | 사서가 필요한 책을 찾아 펼쳐주는 방식 | 답변 전 관련 문서를 검색해 컨텍스트에 넣는 방식      |
| 벡터 DB     | 의미를 찾는 자료 창고                 | 문서의 뜻을 기준으로 검색할 수 있게 해주는 저장소    |
| MCP         | AI용 멀티탭 또는 USB-C포트            | 여러 외부 도구를 표준 방식으로 연결하는 규칙         |
| Eval        | AI용 시험지와 실기 시험               | 결과가 좋은지 반복적으로 평가하는 절차               |
| Guardrail   | 도로의 가드레이로가 공항 보안 검색대  | 위험한 행동을 막거나 확인하는 안전 장치              |
| Sandbox     | 아이가 모래놀이하는 안전한 울타리     | 실제 시스템을 망가뜨리지 않게 격리한 실행 환경       |
| Handoff     | 고객센터에서 전문 부서로 넘기는 일    | 한 에이전트가 다른 에이전트에게 작업을 넘기는 것     |
| Subagent    | 회계팀, 법무팀, QA팀 같은 전문 담당자 | 특정 작업만 맡는 별도 에이전트                       |
| Hook        | 문을 열면 자동으로 켜지는 센서등      | 특정 순간에 자동으로 실행되는 절차                   |
| Compaction  | 긴 회의록을 요약본으로 줄이는 일      | 오래된 대화와 관찰을 압축해 컨텍스트를 아끼는 방식   |
| Artifact    | 작업 결과를 증명하는 영수증과 사진    | 계획서, 스크린샷, 테스트 결과처럼 검토 가능한 산출물 |
