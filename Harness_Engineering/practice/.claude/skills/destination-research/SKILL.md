# Skill: 여행지 정찰 작업법

## 언제 트리거되는가
- 사용자가 "어디로 갈까", "여행지 추천", "후보지 알려줘"라고 말할 때
- destination-scout 에이전트가 호출되었을 때
- 출발지·부모님 정보가 어느 정도 주어진 상태

## 절차

### 1. 입력 확인
다음 정보가 있는지 확인한다. 빠진 항목이 있으면 **추측하지 말고 사용자에게 묻는다**.
- [ ] 부모님 연령대
- [ ] 출발지
- [ ] 여행 일수
- [ ] 부모님 건강 특이사항 (관절, 지병, 알레르기)
- [ ] 계절/시기
- [ ] 선호/비선호

### 2. 후보 선정 기준
- 출발지에서 **편도 이동 3시간 이내** (자차 기준)
- 평지·접근성 좋은 관광지 비율이 높을 것
- 식사 옵션이 다양할 것 (특히 부드러운 음식 선택지)
- 숙소가 1층/엘리베이터 있는 옵션이 있을 것
- 가까운 응급실/병원이 있을 것

### 3. 후보 3~5곳 도출

### 4. 비교표 작성

## 산출물 형식

```
## 여행지 후보 비교

| # | 후보지 | 이동시간 | 추천 이유 | 부모님 친화 포인트 | 주의점 |
|---|---|---|---|---|---|
| 1 | (장소) | (시간) | (...) | (...) | (...) |
| 2 | ... | ... | ... | ... | ... |
| 3 | ... | ... | ... | ... | ... |

## 1순위 추천: (장소명)
(2~3문장 이유)

## 사용자에게 묻기
어느 곳으로 진행할까요? 또는 다른 조건을 더 알려주시면 후보를 다시 정찰하겠습니다.
```

## 품질 체크
- [ ] 후보가 3곳 이상인가
- [ ] 각 후보마다 "주의점"이 비어있지 않은가
- [ ] 부모님 건강 특이사항이 비교에 반영되었는가
- [ ] 마지막에 사용자에게 선택을 묻는가
