# 01. 독자 가이드: 이 책을 끝까지 읽는 법

## 1. 이 책은 어려운 말을 생활 속 장면으로 바꿔서 설명한다.

| 어려운 개념   | 이 책에서 사용하는 비유                                      |
| ------------- | ------------------------------------------------------------ |
| LLM           | 똑똑하지만 회사 규칙을 모르는 신입사원                       |
| 하네스        | 신입사원이 안정적으로 일할 수 있게 해주는 사무실, 도구, 규칙, 검토 체계 |
| 컨텍스트 창   | 지금 책상에 펼친 자료                                        |
| 장기 메모리   | 서랍, 창고, 회의록, 단골 카페의 취향 기록                    |
| 도구 호출     | 직원이 전화, 검색 계산기, 파일함을 사용하는 행동             |
| 권한 관리     | 출입 카드, 결재선, 보안 검색대                               |
| Hook          | 문을 열면 자동으로 켜지는 센서등, 세탁기의 자동 행굼         |
| Eval          | 운전면허 시험, 품질검사표, 채점기준                          |
| Sandbox       | 실험실, 연습장, 격리된 작업 공간                             |
| Progress file | 병원 교대근무 인수인계 차트                                  |

용어가 어렵다 느끼면 `이것이 일상 생활(회사, 주방, 병원등)에서 무엇과 비슷할까?`를 물어보자.

## 2. 이 책의 시각 자료는 장식이 아니라 지도다.

| 시각 요소  | 어떻게 읽으면 좋은가                                       |
| ---------- | ---------------------------------------------------------- |
| 계층도     | "무엇이 위에 있고, 무엇이 아래에 있는가?"를 본다.          |
| 흐름도     | "어떤 순서로 일이 진행되는가?"를 본다.                     |
| 비교표     | "어떤 선택지가 있고, 각각의 대가는 무엇인가?"를 본다.      |
| 체크리스트 | "내 프로젝트에 바로 적용하면 무엇부터 해야하는가?"를 본다. |
| 실습 도표  | "내가 지금 무엇을 관찰해야 하는가?"를 본다.                |
